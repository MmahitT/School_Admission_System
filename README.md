# School Admission System

Seat-safe online admission for a private school (React + ASP.NET Core + PostgreSQL).

> Work in progress — full documentation is completed in Phase 8.

## Quick start

```bash
cp .env.example .env      # then set POSTGRES_PASSWORD
docker compose up --build
```

Open http://localhost:8080.

See [PROJECT_SPECIFICATION.md](PROJECT_SPECIFICATION.md) for the design and [ASSUMPTIONS.md](ASSUMPTIONS.md) for assumptions.
